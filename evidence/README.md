# Evidence Notes

The images in this folder were extracted from the author's original lab documentation and renamed for portfolio use.

- Unrelated floating command-window overlays were removed from selected screenshots. The underlying security evidence, event fields, nodes, labels, and relationship details were not altered; where an overlay had already obscured content in the source, no hidden evidence was invented.
- Credential hashes, passwords, payloads, student identifiers, and complete assignment files are not included.
- Names shown in the Active Directory and BloodHound images are synthetic identities generated inside the lab.
