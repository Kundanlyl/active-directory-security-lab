# Security and Responsible-Use Notice

This project documents authorized testing in a personally controlled lab. It must not be used to access, test, or disrupt systems without explicit permission.

The repository intentionally excludes:

- reusable passwords and credential hashes;
- malware or payload files;
- raw SharpHound datasets;
- personally identifying school records;
- instructions designed to facilitate unauthorized access;
- original assignment prompts or third-party course content.

The screenshots contain only synthetic lab identities, private lab addresses, and non-production hostnames.
